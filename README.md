# 후쿠오카 2026

2026년 11월 23–27일 가족여행 일정 앱. 단일 HTML 파일에 사진·지도가 모두 포함돼 있어 오프라인에서 동작합니다.

## 사용

GitHub Pages 주소를 **사파리**로 연 뒤 공유 → **홈 화면에 추가**.
주소창 없이 전체 화면으로 실행됩니다.

## 구성

- `index.html` — 앱 본체 (사진 83장, 일자별 지도 6장 내장)
- `sw.js` — 오프라인 캐시
- `manifest.webmanifest` — 홈 화면 아이콘·전체 화면 설정
